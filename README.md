# Tyson - Offline Voice Assistant (Kotlin + Vosk)

Offline wake phrase: "hey tyson"

This repository contains an Android Studio project scaffold for an offline voice assistant named Tyson. It uses Vosk for offline ASR and an AccessibilityService to perform device actions (open apps, call contacts, send WhatsApp messages, SMS, volume, home/back).

See app/README.md for setup and installation instructions.
